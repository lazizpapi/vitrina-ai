# Vitrina AI

Телеграм-бот, который превращает одно фото товара в полный набор карточек для
Uzum, Wildberries и Ozon.

Продавец присылает фото, название, цену и три преимущества на узбекском или
русском. В ответ приходят четыре изображения 1200×1600, 3:4, sRGB JPEG, готовые
к загрузке:

| Карточка | Что это |
|----------|---------|
| Главное фото | Его собственный товар на чистом студийном фоне. Форма, цвет и надписи не тронуты. |
| В интерьере | Товар в реальной сцене, подходящей его категории. |
| С моделью | Человек держит товар или пользуется им. |
| Инфографика | Товар с ценой и тремя преимуществами поверх. |

Генерация работает на [Higgsfield API](https://docs.higgsfield.ai/docs). Оплата —
в сумах через Click или в Telegram Stars.

## Зачем это

В сентябре 2026 Higgsfield открыл API с оплатой за запрос, и один из их команды
предложил $50 000 тому, кто построит на нём конкурента. Универсальных студий уже
и так много. Но продавец в Ташкенте не может оплатить американский API местной
картой, не пишет промпты по-английски и не знает, что главное фото на
маркетплейсе обязано сохранять реальный товар без изменений. Вот этот разрыв и
есть продукт.

## Решения в основе

**Каталог карточек — это контракт.** В `src/generation/cards.ts` лежит каждый тип
карточки со своим эндпоинтом, соотношением сторон, разрешением и указаниями для
промпта. Добавить тип карточки или сменить модель — это правка данных, а не кода.

**Текст никогда не рисует модель.** Диффузионные модели ломают кириллицу и
узбекскую латиницу. Модель отдаёт чистый фон, а `src/render/infographic.ts`
накладывает плашку с ценой и преимущества через sharp, используя вшитый шрифт
Noto Sans, чтобы набор шрифтов в контейнере не имел значения.

**Главная карточка — это правка, а не генерация.** Модераторы Uzum и Wildberries
требуют, чтобы главное фото показывало реальный товар с неизменной формой, цветом
и комплектацией. Это ограничение зашито в каждый промпт, а фото продавца всегда
уходит как референс.

**Один провайдер, один шов.** `src/generation/provider.ts` — интерфейс на четыре
строки. Сегодня у него одна реализация; вторая будет новым файлом, а не
переработкой.

**Начисления идемпотентны.** Кредиты двигаются через функцию Postgres с ключом
`(reason, ref_id)`. Ни повторная доставка платежа Telegram, ни повторный вызов
Complete от Click не начислят дважды.

**Неполный набор бесплатен.** Если две карточки из четырёх не получились,
продавец забирает те, что вышли, а кредит возвращается.

## Стек

TypeScript на Node 22+, [grammY](https://grammy.dev) для Telegram, Supabase для
Postgres и хранилища, [sharp](https://sharp.pixelplumbing.com) для композиции,
OpenAI для перевода брифа с узбекского или русского в английские сценарные
промпты, и официальный SDK Higgsfield.

## Установка

```bash
npm install
npm run fonts
cp .env.example .env
```

1. **Higgsfield.** Создайте ключ на [open.higgsfield.ai](https://open.higgsfield.ai),
   пополните баланс, впишите `keyId:keySecret` в `HF_API_KEY`.
2. **Supabase.** Создайте проект, выполните `db/migrations/001_init.sql` в SQL-редакторе,
   скопируйте URL проекта и service-role ключ в `.env`. Бакет создастся сам при первом запуске.
3. **Telegram.** Создайте бота через [@BotFather](https://t.me/BotFather) и впишите токен в `BOT_TOKEN`.
4. **OpenAI.** Подойдёт любой ключ; модель задаётся в `OPENAI_MODEL`.
5. **Click (необязательно).** После договора с мерчантом заполните четыре переменные
   `CLICK_*`, укажите в кабинете Shop API адреса `$PUBLIC_URL/click/prepare` и
   `$PUBLIC_URL/click/complete`, поставьте `CLICK_ENABLED=true`. До этого бот
   продаёт только за Telegram Stars.

```bash
npm run dev
```

## Оплата

Telegram требует, чтобы цифровые товары внутри бота оплачивались в Stars, поэтому
Stars доступны всегда. Click подключается как внешняя ссылка на оплату — это
правилами разрешено, — а кредиты начисляются через колбэки Shop API. Оба пути
пишут через одни и те же идемпотентные начисления.

Пакеты: 25 000 сум за один товар, 100 000 за пять, 350 000 за двадцать. Один
кредит — это один товар, то есть четыре изображения. Каждому новому пользователю
даётся одна бесплатная главная карточка.

## Тесты

```bash
npm test
```

Покрыты подпись Click и его конечный автомат, разбор цены и преимуществ, сборка
промптов вместе с офлайн-запасным вариантом, рендер инфографики и весь конвейер
генерации на подставном провайдере. Ни один тест не ходит в сеть.

## Развёртывание

Работает как один долгоживущий процесс Node. На Railway задайте переменные окружения,
откройте порт и укажите Click публичный домен для колбэков. Проверка живости —
`GET /health`.
